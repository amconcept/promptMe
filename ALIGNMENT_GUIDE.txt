GRID ALIGNMENT COMPARISON
═══════════════════════════════════════════════════════

The difference between 'start' and 'end':

─────────────────────────────────────────────────────
1. justify-content: start (LEFT ALIGNMENT)
─────────────────────────────────────────────────────

    Viewport
    ┌───────────────────────────────────────────┐
    │                                           │
    │  Grid starts here →  [Column][Column]   │
    │                        200px   200px      │
    │                                           │
    └───────────────────────────────────────────┘

    Result: Grid aligned to the LEFT edge
    Use when: You want the grid to start at the left side
             (or within a left-aligned container)

─────────────────────────────────────────────────────
2. justify-content: end (RIGHT ALIGNMENT)
─────────────────────────────────────────────────────

    Viewport
    ┌───────────────────────────────────────────┐
    │                                           │
    │            [Column][Column] ← Ends here   │
    │            200px   200px                 │
    │                                           │
    └───────────────────────────────────────────┘

    Result: Grid aligned to the RIGHT edge
    Use when: You want the grid to end at the right side
             (or within a right-aligned container)

─────────────────────────────────────────────────────
3. justify-content: center (CENTERED) [Default]
─────────────────────────────────────────────────────

    Viewport
    ┌───────────────────────────────────────────┐
    │                                           │
    │         [Column][Column]                  │
    │         200px   200px                     │
    │                                           │
    └───────────────────────────────────────────┘

    Result: Grid centered horizontally
    Use when: You want the grid centered on the page

═══════════════════════════════════════════════════════
WHICH ONE TO USE?
═══════════════════════════════════════════════════════

✅ 'start'  → Left-align the grid
✅ 'end'    → Right-align the grid  
✅ 'center' → Center the grid (most common)
